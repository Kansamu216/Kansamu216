主要做 Minecraft 模组,顺手把一台 13 寸商务本折腾成了 Mac,也维护几个自己要用的服务。踩过的坑都写清楚,省得下次再踩。

## 主要项目

**Minecraft 模组**

- **[Voidkit](https://github.com/KokuuWork/voidkit)** · `Kotlin` — 纯服务端模组套件,家 / 传送点 / 权限 / 经济等;组件各自独立成 jar,按需装拆
- **[精致网络 / Refined Network](https://github.com/KokuuWork/refined-network)** · `Java` — Refined Storage 2 附属,无线合成、样板编辑、库存监控;0.4.1 已发布,0.5.0 开发中

**系统与驱动**

- **[Dynabook G83/HU · macOS Tahoe](https://github.com/Kansamu216/dynabook-g83-macos-tahoe)** — 13.3" 商务本跑 macOS Tahoe 26 的 OpenCore EFI 与定制核显驱动,另维护 [WhateverXe 适配分支](https://github.com/Kansamu216/WhateverXe-1145G7-fork)

**站点与服务**

- **[KokuuSkin Server](https://github.com/Kansamu216/kokuu-skin)** — 谷雨工作室皮肤站,Blessing Skin Server 的插件化定制版

## 技术栈

Kotlin · Java 17 / 21 · Gradle · Minecraft 1.20.1 / 1.21.1 · NeoForge / Forge / Fabric · OpenCore / Lilu
